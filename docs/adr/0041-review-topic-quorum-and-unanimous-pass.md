# Review topics freeze quorum and require unanimous PASS

Each Review topic freezes a required eligible-reviewer count when it is created, defaulting to the number of eligible reviewer-participants. The final re-review remains blocked until that quorum is met and must include at least one eligible reviewer who did not submit an initial finding; every re-review uses fresh independent Sessions. Any counted `FAIL` vote yields `FAIL`, otherwise any counted `CONDITIONAL_PASS` yields `CONDITIONAL_PASS`, and only unanimous counted `PASS` votes with no unresolved blocking finding yield `PASS`. Owner-participants and moderators never count toward quorum or Gate votes. This deliberately favors separation of duties and evidence completeness over majority approval, while keeping a smaller explicit quorum available for a Topic that declares alternate eligible reviewers.
